# Minecraft Crafting Reference

**How Everything in Minecraft Is Made**

*A living reference. Every day a new chapter of recipes lands here.*

## HOW TO USE THIS BOOK

Each entry shows the exact recipe — the crafting grid, the materials, the step-by-step build, and how the item fits into your progression. Crafting grids use letters that map to items in a legend below each grid.

## CHAPTER 5 — MACHINES & REDSTONE CONTRAPTIONS

### Piston

**Yield:** 1 piston

```

**Legend:** A = Planks, B = Cobble, C = Iron, D = Redstone

**Tip:** Pushes blocks forward when powered. Combine with a Slimeball to make a Sticky Piston (which also pulls blocks back). Foundation of all redstone contraptions: doors, elevators, traps, farms.

**Tip:** The face (with the “U” shape) detects block changes and emits a redstone pulse. Essential for automatic farms — detects when a crop is grown, a piston extends, etc.

### Hopper

**Legend:** A = Cobble, B = Bow, C = Redstone

### Dropper

**Yield:** 1 dropper

```

```

**Legend:** A = Cobble, B = Redstone

### Redstone Repeater

**Yield:** 1 repeater

```

[A] [A] [A]

```

**Legend:** A = Redstone, B = Stone

**Tip:** Extends redstone signal up to 15 blocks, delays signal timing (right-click to cycle 1-4 ticks), and only passes signals from back to front (acts as a diode).

### Redstone Comparator

```

**Legend:** A = Quartz, B = Redstone, C = Stone

**Tip:** Has three modes: compare (outputs signal only if input is above reference), subtract (outputs difference), and measure container fullness (when facing a chest/hopper/furnace).

## CHAPTER 10 — SMELTING — FURNACE RECIPES

How the furnace works: Place the ingredient in the top slot, fuel (coal, charcoal, wood, lava bucket, etc.) in the bottom slot, and wait. Each operation takes about 10 seconds. A single piece of coal smelts 8 items. Multiple furnaces can run at once for faster processing. Ore Smelting
